# Delta Avtomaktab - Android Ilova Loyihasi

Ushbu loyiha Delta Avtomaktab veb-dasturining Android operatsion tizimi (APK) uchun WebView wrapper loyihasidir.

## 🛠️ O'rnatish va APK yaratish ko'rsatmasi:

1. **Android Studio-ni oching**:
   Kompyuteringizda **Android Studio** dasturini oching.
   
2. **Loyihani import qiling**:
   `Open` (Ochish) tugmasini bosing va ushbu `android_app` papkasini tanlang. Android Studio barcha kerakli fayllarni o'zi yuklab oladi va sinxronizatsiya qiladi.

3. **APK-ni yig'ish (Build)**:
   - Yuqori menyudan **Build > Build Bundle(s) / APK(s) > Build APK(s)** bo'limini tanlang.
   - Yig'ish yakunlangandan so'ng, ekranning o'ng pastki qismida chiqadigan xabardan **locate** tugmasini bosing.
   - Yaratilgan `app-debug.apk` faylini telefoningizga o'rnatishingiz mumkin!

## 📱 Ilovadan foydalanish:

1. **Birinchi marta ochilganda**:
   Ilova birinchi marta ochilganda sizdan server manzilini (localtunnel havolasini) kiritishni so'raydi.
   
2. **Ulanish**:
   Kompyuterdan olingan onlayn localtunnel havolasini (masalan: `https://ten-jeans-matter.loca.lt`) yozing va **"TIZIMGA ULANISH"** tugmasini bosing. Ilova dasturingizni xuddi telefondagidek to'liq ekranda ochib beradi.

3. **Manzilni o'zgartirish**:
   Havola har safar o'zgarganida yangi manzilni kiritish uchun:
   - Telefoningizning menyu tugmasini bosing (yoki ekran tepasidagi sozlamalar belgisi/menyu orqali).
   - **"Server manzilini o'zgartirish"** bandini tanlang va yangi havolani kiriting.

4. **Sahifani yangilash**:
   Sahifani istalgan vaqtda tepadan pastga tortib (**Swipe-to-Refresh**) yoki menyudan **"Sahifani yangilash"** orqali yangilashingiz mumkin.
